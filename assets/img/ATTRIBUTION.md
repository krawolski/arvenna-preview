# Bildnachweis / Image attribution

All photography on this site comes from **Pexels** under the
[Pexels License](https://www.pexels.com/license/), which permits free commercial
use without attribution. We list sources anyway, so the origin of every file is
traceable and replaceable.

**Nothing is hotlinked.** Every image was downloaded and is served from
`assets/img/`. No visitor IP is sent to a third party by loading a photo, which
keeps `datenschutz.html` accurate.

Each image exists as WebP at two widths (1600 px and 800 px) and is served via
`srcset`. Below-the-fold images use `loading="lazy"`. A blurred placeholder is
inlined as a data URI so photos resolve out of a blur instead of popping in.

**Deliberately excluded:** `plus.unsplash.com/premium_photo-*` results. Those are
Unsplash+ and are NOT covered by the free licence, despite appearing in ordinary
image search results.

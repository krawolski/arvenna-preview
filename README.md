# Arvenna, Vorschau / Preview

Vorschau der neuen Website für **Arvenna**, eine Schweizer Webagentur.
Reines statisches HTML, CSS und Vanilla JS. Kein Build, kein npm, kein Framework.

**Live:** https://krawolski.github.io/arvenna-preview/

## Was man anschauen sollte

- **Startseite**, deutsch. Oben rechts zwei Punkte: Farbvariante umschalten
  (Schweizer Rot oder Alpengrün). Die Wahl bleibt gespeichert.
- **Beispielprojekte**: Branche anklicken, die Vorschau lädt die echte Demoseite
  in einem verkleinerten Browserfenster. Das ist kein Screenshot.
- **Vier Demoseiten**, jede mit eigener Gestaltung:
  [Coiffeur](demos/coiffeur/), [Baufirma](demos/baufirma/),
  [Restaurant](demos/gastro/), [Industrie](demos/robotik/)
- **Englische Fassung** unter [/en/](en/)

## Bekannte Einschränkungen dieser Vorschau

- **Das Kontaktformular sendet nicht.** GitHub Pages führt kein PHP aus, deshalb
  meldet das Formular einen Fehler. Die Prüfung der Eingaben funktioniert.
  Auf dem echten Hosting (LH.pl) läuft `contact.php` normal.
- Impressum und Datenschutz enthalten noch Platzhalter.
- Die vier Demofirmen sind **frei erfunden**.
- Preise sind der freigegebene Stand, aber noch nicht final bestätigt.
